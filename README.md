# Amanda

Repositório de apoio para a criação de infoprodutos, usado com o Claude Code.

## Agente: infoprodutos

Este repositório define um agente especializado (`.claude/agents/infoprodutos.md`) para ajudar na criação de infoprodutos (ebooks, cursos online, mentorias, templates, comunidades pagas).

O agente cobre todo o ciclo:

1. Diagnóstico da área de conhecimento e da audiência
2. Validação da ideia de produto
3. Definição de nicho, avatar e posicionamento
4. Escolha de formato e montagem da oferta
5. Estrutura de conteúdo (índice/currículo)
6. Precificação
7. Copywriting (página de vendas, e-mails, anúncios)
8. Plano de lançamento
9. Orientações sobre plataformas e aspectos operacionais

### Como usar

No Claude Code, dentro deste repositório, peça para usar o agente `infoprodutos` (por exemplo: "use o agente infoprodutos para me ajudar a validar minha ideia de curso sobre X"). O Claude Code carrega automaticamente os agentes definidos em `.claude/agents/`.
